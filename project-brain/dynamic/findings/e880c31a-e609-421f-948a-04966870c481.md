# Reported fat notification queue payloads were a false positive

## Goal
A security review flagged the five new notifications for serializing whole models into the jobs payload, recommending SerializesModels. Illuminate\Notifications\Notification already uses that trait, so every payload held only a ModelIdentifier and the suggested change was a no-op. Verified in vendor and pinned by a test that reads jobs.payload directly, asserts the child's name is absent, then drains the queue and asserts no failed jobs. Recorded so the next reviewer does not re-raise it.
